# Handoff convention

Keep each live handoff in a local location approved by the repository owner. Do not commit session transcripts, secrets or machine paths.

Record the deliverable ID and acceptance criteria, current state, files changed, checks actually run, unresolved risks, and the next action. Separate observations from assumptions. A successor should be able to resume without repeating the investigation.
