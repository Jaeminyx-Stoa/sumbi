# 계획 수립

올바르게 구현하는 데 꼭 필요한 정보만 질문한다. 결과물, 인수 기준, 제약, 예상 실패 사례를 기록한다. 큰 변경에 착수하기 전에 이 기준으로 계획을 비판적으로 검토한다. 작고 되돌릴 수 있는 수정에는 규모에 맞는 절차를 적용한다.

최종 승인을 요청하기 전에 구체적으로 검토할 수 있는 결과물을 준비한다. 파괴적 작업이나 외부 작업에는 기존 승인 절차가 계속 적용된다. 침묵을 승인으로 간주하지 않으며, 요청 범위가 이미 승인되었다면 다시 묻지 않는다.
