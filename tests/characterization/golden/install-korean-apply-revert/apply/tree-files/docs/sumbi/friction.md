# 마찰 피드백

보고서 마지막의 하네스 마찰 항목에는 작업을 막거나 반복하게 한 지침, 도구, 검사를 적는다. 어디에서 막혔고 어떤 영향을 받았는지 짧게 설명한다. 공유하는 출력에는 프롬프트, 대화록, 비밀 정보, 기기 식별자를 넣지 않는다.

지침을 추가하기 전에 반복되는 하네스 마찰을 검토한다. 원인을 해결할 수 있다면 신뢰할 수 있는 검사나 더 단순한 작업 절차를 우선한다. 보고서는 조사의 근거로 삼되, 제안한 수정이 비용을 줄인다는 증명으로 간주하지 않는다.
